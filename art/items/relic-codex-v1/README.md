# 아이템 도감 원화

내장 ImageGen으로 유물18종과 기존 누락10종을 제작했다. 최종 개별PNG는 이 폴더의 relic_*.png18개와 기존아이템ID.png10개다. 원본5장도 보존한다. 유물 프롬프트는 prompts.json, 기존 품목 보완 프롬프트는 existing-prompts.json, 유물 원화 연결은 manifest.json에 기록했다.

기존 아이템 화풍 참고는 art/items/class-equipment-v1.png이며 국가 장식색·검과 방패 세트·활과 쇠뇌·목제 투석기를 구분했다. 원화는 도감 표시용이며 유물 전투 효과 구현과 구분한다. 시트에서 개별 셀만 추출했으며 원본을 덮어 그리거나 재색칠하지 않았다.
