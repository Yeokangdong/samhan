# 상점 아이템 원화

사용자 요청: “상점 아이템 원화도 만들어야 돼”.

제작 완료: 현재 상점의 18개 판매 품목에 대응하는 원화 3장. 기존 SD 캐릭터를 참조한 따뜻한 갈색 윤곽선·애니메이션풍 채색을 공통으로 사용한다. 투명 PNG이며 이름·가격·효과는 별도 HTML로 표시한다. 세 나라가 공통 원화를 사용한다.

| 원화 | 품목 |
|---|---|
| `art/items/weapons-v1.png` | 철검·환두대도·철창·장창·단궁·맥궁·죽간·병법서 (4×2칸) |
| `art/items/equipment-v1.png` | 가죽갑옷·찰갑·도포·곡옥·금귀걸이 (3×2칸, 마지막 칸 비움) |
| `art/items/consumables-v1.png` | 콩주머니·약초·탁주·꿀물·해독초 (3×2칸, 마지막 칸 비움) |

내장 ImageGen을 사용했다. 최종 프롬프트는 `art/items/PROMPTS.json`, 기존 아이템 ID와 아틀라스 칸의 대응은 `art/items/manifest.json`에 저장한다. 표시 코드는 `src/item_art.js`, 스타일은 `src/ui/item-art.css`다.

구현 완료: 판매 카드·현재 장착 장비·장비 교체 목록·소지품 선택 목록에 원화를 적용했다. 18개 판매 ID와 원화 매핑의 일치, 투명 채널, 브라우저의 상점 표시를 확인했다. 가격·효과·판매 목록·구매 및 장비 저장 방식은 유지한다.

미구현 목표: 상점에서 아직 판매하지 않는 상급 무기·상급 방어구·국보·군주 보물의 원화. 새 품목이 실제 추가될 때 같은 화풍과 아이템 ID 기준으로 제작한다. 이번 작업은 해당 미래 아이템 전체의 원화 완료나 아이템 밸런스 개편을 뜻하지 않는다.


## 상점 특수 장비 v2 (2026-10-23)

상점용 고가 특수 장비를 새로 그렸다. weapons-v2.png는 무기 8종(4×2), equipment-v2.png는 방어구 3종·장신구 2종(3×2, 마지막 칸 비움)이다. 내장 ImageGen을 사용했고 두 파일 모두 RGBA 투명 채널을 확인했다. 최종 프롬프트와 셀 순서·장비명 초안은 special-shop-v2.json에 있다.

이 자산은 신규 상점 전용 아이템 제작용이며 현재 기본 장비·상점의 v1 원화 매핑은 유지한다. 장비별 신규 ID, 판매 목록·가격·능력치, 고유 효과와 UI 연동은 기획서의 후속 구현 목표다. 소비품 원화와 가격은 유지한다.

## 검과 방패 세트 원화 — 2026-10-23

사용자 요청: “장검만 나오게 하지말고 장검 방패 세트로 같이 그려”. 검 계열의 아이템 원화는 검 단독 대신 장검과 원형 방패가 함께 보이는 한 세트로 그린다. 칼날·자루와 방패 형태를 모두 읽을 수 있도록 같은 아이템 칸 안에 배치한다. 일반 철검·환두대도 원화와 상점 특수 장검 두 종류에 동일한 기준을 적용한다. 창·활·죽간·병서의 칸 순서는 유지한다.

기본 무기 시트는 art/items/weapons-sword-shield-v1.png, 특수 무기 시트는 art/items/weapons-special-sword-shield-v1.png로 별도 저장한다. 이전 원본은 보존한다. 일반 무기의 기존 아이템 ID에 새 원화를 연결하며 특수 무기의 신규 판매 ID·가격·고유 효과 구현은 기존 후속 작업 구분을 유지한다. 방패를 함께 그리는 이번 요청만으로 별도 방패 슬롯이나 추가 방어력 수치를 만들지는 않는다. 원화에 실제 착용한 장비를 아이템으로 맞추는 앞서 취소된 작업은 재개하지 않는다.

## 아이템 원화 통일과 사기·이동력 아이템 추가 (2026-10-24)

- 출처·사용자 확정: 현재 작업 채팅의 “짚신과 진군깃발이 다른아이템 원화와 이질감이 있다 사기를 올려주는 아이템에 사탕과 토끼인형 추가 이동력 올려주는 아이템에 가죽신 천사날개 추가”.
- 구현: 기존 짚신(현재 명칭 가죽신)·진군 깃발의 간단한 SVG를 기존 equipment-v1.png의 갈색 윤곽선·손그림 질감·애니메이션 채색에 맞춘 개별 PNG 원화로 교체했다. 사탕·토끼인형·가죽신·천사날개도 같은 화풍의 개별 PNG로 제작했으며 글자와 효과는 별도 HTML로 표시한다. 세 나라 장군 선택 상점에서 구매·장신구 장착·해제·저장을 제공한다. 기존 아이템 ID와 저장 자료를 유지한다.
- 도우미 설정·조정 가능: 사탕 사기 +5 / 100냥, 토끼인형 사기 +15 / 400냥, 가죽신 이동력 +1 / 150냥 (다른 작업의 최신 명칭 변경과 기존 가격을 유지), 천사날개 이동력 +2 / 700냥. 사용자가 지정한 것은 아이템 종류와 주효과이며 구체적 수치·가격은 이번 구현의 임시 밸런스다. 사탕도 기존 진군 깃발과 같은 장신구 방식이며 소비해서 사기를 올리는 소모품은 아니다. 장신구 한 칸을 사용하므로 중복 장착하지 않는다.
- 실제 전투 연결: 낭비성은 저장된 장신구 이동력 보너스를 이동 범위와 선택 정보에 적용한다. 천사날개도 통상 지형 비용·진입 불가 지형을 따른다. 사기 보너스는 공통 HeroData 능력치 계산에 반영되며 낭비성 전용 화면의 사기 판정·전투 전체 완성은 이번 추가 범위가 아니다.
- 제작 자료: art/items/manifest.json, art/items/ACCESSORY_PROMPTS.json, src/item_art.js, src/hero_data.js, src/deployment_kit.js, src/kim_map.js. 내장 ImageGen 사용. 검증 결과는 아래 작업 기록에 별도로 남긴다.

- 병행 변경 조정: 다른 작업에서 확정된 짚신 → 가죽신 명칭 변경을 보존한다. 가죽신은 기존 straw_shoes ID·150냥·이동력 +1에 새 가죽신 PNG를 연결하고 별도 leather_shoes 중복 판매 항목은 만들지 않는다. 요청 당시 짚신 교체용으로 제작한 straw-shoes-v2.png는 제작 자료로만 보존한다. 가죽갑옷·도포 판매 제거 변경도 유지한다.

### 아이템 추가 실제 검증 (2026-10-24)

- 실제 검증: `node build.js`, `node tools/check-accessories.cjs`, `node tools/check-accessory-art.cjs` 통과. 삼국 상점 각각 PC 1440×900·모바일 가로 844×390에서 새 원화 5개 로딩과 가죽신 중복 없음, 브라우저 오류·404 없음 확인. 구매·장착·새로고침 후 저장 유지, 공통 능력치 사기 +5/+15, 낭비성 천사날개 장착 시 이동력 5→7 및 이동 가능 칸 57→95 증가를 검증했다.
- 원화 6개 PNG의 실제 투명 알파 채널과 이미지를 직접 확인했다. 짚신 원화는 보존용이며 상점에는 최신 가죽신 원화를 사용한다. PC·모바일 상점 화면도 직접 확인했다.
- 원화 파일: `art/items/straw-shoes-v2.png` (보존), `art/items/battle-banner-v2.png`, `art/items/candy-v1.png`, `art/items/rabbit-doll-v1.png`, `art/items/leather-shoes-v1.png`, `art/items/angel-wings-v1.png`. 최종 프롬프트 전체는 `art/items/ACCESSORY_PROMPTS.json`에 저장했다.

## 보유 장비 확대·창 아이콘 잘림 수정 (2026-10-24)

구현 완료: 장수 정보의 보유 장비를 한 줄에 한 장비씩 표시하며, 큰 아이콘 왼쪽·이름과 효과 오른쪽으로 배치한다. 아이콘은 PC·태블릿 112px, 휴대폰 및 높이 540px 이하 가로 화면 96px로 확대했다. 장비명은 일반 화면 24px, 작은 화면 21px로 표시하고 미장착 항목도 너비 안에 맞춘다.

창 시트의 등분 경계에 옆 환두대도 방패 끝이 들어오던 문제를 고쳤다. 철창은 원본 1774×887 안의 (904, 15, 393, 415), 장창은 (1348, 14, 409, 415) 영역만 SVG 표시 창으로 잘라 종횡비를 유지한다. 원본 PNG는 유지하며 `src/item_art.js`, `src/ui/item-art.css`, `art/items/manifest.json`에 표시 규칙을 기록했다. PC·태블릿·가로 휴대폰 4가지 화면에서 확대·이름 겹침·가로 넘침을 확인했고, 장비 교체·새로고침 후 저장 유지·창 원화 표시를 `tools/test-equipment-ui.js`로 검증했다.

## 음식·삼국시대 장비·정신력 아이템 확대 (2026-10-24)

### 출처와 사용자 확정

현재 아이템 작업 채팅의 사용자 요청 “귀리죽 보리밥 쌀밥 추가하고 삼국시대의 전통 무기나 방어구 장신구 추가 정신력 올려주는 아이템 2종 추가”와 후속 “정신력 올려주는 아템 박카수 추가”를 반영한다. 박카수는 앞선 정신력 2종에 추가하는 세 번째 품목이다. 아이템 이름과 정신력 상승 방향은 사용자 확정이다. 구체적인 전통 장비 인선·능력치·가격·슬롯은 도우미의 구현안이며 조정 가능하다.

정신력은 공통 능력치 spi를 높인다. MP 회복과 구분한다. 박카수는 실제 의약품 설명이 아닌 코믹한 가상 음료이며, 이번 구현은 기존 장신구 슬롯을 사용하는 지속 장착 효과다. 소비·영구 능력치 상승·전투 중 일시 버프는 추가하지 않는다. 목걸이·팔찌·박카수는 장신구 한 칸을 서로 교체해 장착한다. 음식은 기존 소모품 규칙에 따라 소지품·보조에 챙긴다.

기존 데이터와 원화가 있는 환두대도(공격 +16 / 600냥), 철창(공격 +8 / 200냥), 장창(공격 +15 / 550냥)도 삼국 공통 출진 상점의 판매 목록에 추가한다. 새 데이터 8종과 기존 장비 판매 추가 3종을 구분한다. 무기는 병종별 검·창 장착 제한을 따른다. 가죽갑옷·도포 판매 제거와 기존 짚신 ID의 가죽신 명칭 변경은 유지한다.

### 구현 및 원화 제작 상태

HeroData 아이템 정의·상점 구매·장착/해제·공용 창고·소지품 편성·저장을 연결했다. 공통 능력치 계산에서 공격 +20·방어 +16·정신력 +6/+10/+8을 검증했다. 낭비성 전용 맵은 이동 시제품이므로 음식 사용·정신력 전투 판정 전체가 구현됐다는 뜻은 아니다.

원화는 기존 equipment-v1.png·consumables-v1.png와 같은 갈색 윤곽선·손그림 질감·애니메이션풍 채색으로 내장 ImageGen을 사용한다. 검 원화는 기존 사용자 확정인 장검+원형 방패 세트 구성을 유지한다. 투명 PNG이며 이름·가격·효과는 별도 HTML이다. 원화 제작과 화면 검증을 완료했으며 결과는 아래에 기록한다.

이전 `check-food-equipment.cjs` 검사는 병행 상점 개편에서 유리구슬 목걸이 판매가 제거되어 과거 판매 목록 가정으로 실패했다. 본 변경의 최신 전용 검사 두 개는 현재 상점 구성을 기준으로 통과했다. 과거 검사 통과 기록을 이번 실행 결과로 대체 보고하지 않는다.

## 상점 54종 원화 확대

새 아이템 데이터 26종·기존 육도삼략 판매 추가로 판매 품목 54종을 구성한다. 신규 원화 24종은 shop-armors-v3.png(3×2), shop-accessories-v3.png(2×2), shop-meals-v3.png(3×2), shop-drinks-v3.png(3×2), shop-mounts-v3b.png(2×1)의 시트 5장으로 제작했다. 무기 추가 3종은 기존 weapons-special-sword-shield-v1.png의 4·6·7번 칸을 사용한다. 프롬프트는 SHOP_EXPANSION_V3_PROMPTS.json, 전체 판매 ID·초안 밸런스는 shop-expansion-v3.json이다. 내장 ImageGen 사용. 말 시트의 경계 여백을 보정하고 최종 검증 상태를 아래 기록한다.

말 시트는 각 칸의 여백을 넓힌 shop-mounts-v3b.png를 최종 사용한다. 보정 전 shop-mounts-v3.png는 비교용으로만 보존하며 게임에는 연결하지 않는다.

### 상점 54종 확대 완료·실제 검증

무기 10·방어구 10·장신구 10·소모품 20·말 4종(기존 2종+신규 청풍마·호위마 2종), 총 54개 고유 판매 ID로 확정했다. 신규 아이템 정의 26종과 기존 육도삼략 판매 추가를 구분한다. 신규 26종을 모두 구매한 검사 합계는 14,350냥이며 공용 창고·장착·소모품 편성·새로고침 저장을 검증했다. 기본 장착 말·시작 장신구 및 기존 판매 제외품은 계속 상점에서 제외한다.

내장 ImageGen으로 신규 방어구 6·장신구 4·소모품 12·말 2종에 해당하는 원화 24종을 시트 5장으로 제작해 적용했다. 최종 파일은 art/items/shop-armors-v3.png, shop-accessories-v3.png, shop-meals-v3.png, shop-drinks-v3.png, shop-mounts-v3b.png다. 말 시트의 인접 칸 꼬리 간섭을 재배치로 보정했고 귀·발굽·꼬리 전체와 셀 경계를 직접 확인했다. 시트 5장의 실제 투명 알파와 모서리 투명도를 검사했다. 무기 추가 3종은 기존 상급 시트 원화를 사용한다. 프롬프트·최종 보정 프롬프트는 art/items/SHOP_EXPANSION_V3_PROMPTS.json에 저장했다.

`node build.js`, `node tools/check-shop-expansion.cjs --art` 통과. 정확한 분류 수량·54개 ID 중복 없음·전 품목 원화 매핑, 무기와 말의 병종 장착 조건, 신규 아이템 구매·자금 차감, 방어구·장신구·말 교체, 소모품 두 종류 제한·보존을 확인했다. 삼국 각각 1440×900·844×390·667×375의 9개 화면 조합에서 486회 판매 원화 로딩을 확인했고 브라우저 오류·404는 없었다. PC 방어구·장신구·군량·말 분류와 모바일 화면을 직접 확인했다. 검증 자료는 tmp/shop-expansion-checks/다.

확정 사양은 판매 종수와 말 추가 2종이며, 새 이름·세부 효과·가격은 조정 가능한 초기 구현안이다. 새 소비품의 체력·MP·상태 회복 데이터 연결과 출진 편성 검증을 전투 연출·모든 장의 승패 구현 완료로 확대 보고하지 않는다.
