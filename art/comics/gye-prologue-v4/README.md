# 백제 프롤로그 만화 원화

내장 ImageGen으로 제작한 20개 독립 사건 장면이다. 2×2 장면 시트 다섯 장과 얼굴 보호 좌표를 실제 게임에 연결했다.

- 최종 시트·생성 프롬프트·수정 내역: `PROMPTS.json`.
- 페이지별 원화·시트 내 위치·얼굴 보호 영역: `illustrations.json`.
- 대사·장군 5명·별도 군주: `../gye-prologue-v3/storyboard.json`.
- 공통 배경: `../backgrounds-v1/gye.png`.
- 기존 초상 나열 화면은 현재 프롤로그에서 사용하지 않는다. 수정 전 시트는 제작 기록으로 보존하며 corrected 시트를 최종 사용한다.
