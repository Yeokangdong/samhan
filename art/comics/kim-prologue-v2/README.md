# 장수 다섯, 명령 하나

사용자 요청으로 기존 김유신 프롤로그를 삭제한 뒤 새로 제작한 20페이지 코믹 출정극이다.

진평왕과 장수 다섯 명(주인공 대장군 김유신, 김서현, 김흠순, 알천, 김품일), 총 여섯 명이 등장한다. 모두 기존 여성 코믹 SD 설정을 따른다. 신라의 모든 등장인물은 경상도 말씨를 쓰되, 왕의 질문·김유신의 기세·김서현의 수습·김흠순의 식사 농담·알천의 건조함·김품일의 점검 말투를 구분한다.

- `storyboard.json`: 20페이지 대사와 장면, 인물 설정의 기준 데이터.
- `cast.png`: 내장 ImageGen으로 제작한 여섯 인물의 그림체·외형 기준 시트.
- `sheet-01.png` ~ `sheet-05.png`: 내장 ImageGen으로 새로 만든 서로 다른 20개 장면. 각 시트의 2×2 구획을 페이지별로 따로 표시한다.
- `PROMPTS.json`: 생성 프롬프트와 기준 이미지 기록.
- `preview.png`: 실제 게임 뷰어 첫 페이지 확인 이미지.
- `read.html`: 프로젝트 게임 뷰어로 이동하는 진입 파일.

그림에는 대사를 넣지 않으며, 페이지별 문답은 HTML로 표시한다. 마지막·건너뛰기는 장수 선택으로 연결하고 편성이 끝나면 낭비성으로 들어간다. 이전 프롤로그 저장 키는 이어받지 않는다.

20페이지 전체 대사·콘티는 `docs/story/kim-prologue.md`, 사용자 요청과 변경 이력은 `docs/작업결정기록.md`, 전체 성격·사투리 시트는 `docs/인물성격시트.md`에 기록한다. 개별 인물의 만남과 농담, 초기 전장 참여는 창작 각색이다.

## 만화 말풍선 연출 (2026-10-23)

새 프롤로그는 만화 말풍선으로 연출한다. 그림 아래 대사 목록을 없애고, 현재 말하는 인물의 대사를 그림 위의 흰 말풍선으로 순서대로 보여 준다. 화자 이름을 표시하며 말풍선 꼬리는 사용하지 않는다. 화면 누르기·오른쪽 방향키·다음 대사로 진행하고, 왼쪽 방향키·이전으로 되돌아간다. 한 장의 마지막 대사 다음에는 다음 장으로 넘어간다. 페이지와 대사 위치를 함께 저장해 이어보며, 20장 모아 보기에서 장을 고르면 첫 대사부터 시작한다. 글자는 원화에 합성하지 않고 별도 HTML 레이어로 유지한다. 모든 사투리와 인물별 성격을 유지하고 작은 화면에서도 본문 글자를 16px 이상으로 표시한다. 천하정세의 UI 없는 이야기 연출 기준은 별도로 유지한다.

## 얼굴 보호와 화자 좌표

최신 사용자 지시 17·18에 따라 말풍선은 반드시 원화 안에 배치한다. 원화 바깥의 전용 여백은 없앤다. 컷별 얼굴 보호 영역을 피해 원화 안의 빈 공간에 배치하며 말풍선 꼬리는 사용하지 않는다. 말풍선 안의 대사 순번·숫자·진행 화살표는 삭제한다. 화자 이름은 모바일 20px·PC 23px로 키워 본문과 구분한다. 작은 화면에서 긴 대사가 빈 공간에 한 번에 들어가지 않으면 말풍선 내부를 세로로 스크롤해 읽는다. 20장 원화를 직접 확인해 각 인물의 입 좌표와 얼굴 보호 영역을 컷별로 기록하며 화면 크기가 바뀌어도 그림의 실제 표시 영역을 기준으로 꼬리 끝을 계산한다. 최신 사용자 지시 16에 따라 말풍선 꼬리를 완전히 제거한다. 현재 화자는 말풍선 안의 이름으로 구분한다. 얼굴 보호 영역은 배치 검증 자료로 유지하며 꼬리 좌표·경로는 화면에 사용하지 않는다. 기준 데이터는 storyboard.json 각 페이지의 layout.faces이며 재생성 때 보존한다.
